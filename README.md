# Open Banking Dedicated Interface

This repository contains one-page, A4 PDF documents introducing and explaining TechnoXander’s [Open Banking Dedicated Interface (APICall)](https://technoxander.com/open-banking-dedicated-interface/).

## About the solution

TechnoXander APICall is an Open Banking Dedicated Interface for UK banks and financial institutions. It provides RESTful APIs for AISP, PISP and CBPII services, with FAPI-compliant security, eIDAS/Open Banking certificate support, a dedicated sandbox, flexible deployment options and reporting capabilities (including support for REP020 return requirements as stated on the solution page).
